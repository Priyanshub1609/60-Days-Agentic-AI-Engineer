# 60 Days Agentic AI Engineer

A practical, project-based journey to build reliable AI agents with Python, local LLMs, tool use, structured outputs, validation, and orchestration.

## Repository roadmap

| Day | Focus | Projects |
|---|---|---|
| Day 01 | Agentic AI foundations | Chatbot, interview assistant, study assistant |
| Day 02 | Tool calling and memory | Agent with tools, personal AI assistant |
| Day 03 | Prompt engineering and reliable outputs | Task planner, structured output, resume analyzer, interview preparation agent |

## Tech stack
- Python
- Ollama with `qwen2.5:3b`
- Pydantic
- JSON and JSON Schema

## Setup

1. Install Python 3.10 or newer.
2. Install and start [Ollama](https://ollama.com/).
3. Pull the model:

```bash
ollama pull qwen2.5:3b
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

Each day folder has its own README and requirements file with project-specific instructions.

## Learning approach
The repository records hands-on exercises and projects completed throughout the 60-day learning journey. Projects may require a running local Ollama service.

# Day 1 — Introduction to Agentic AI Development

## Overview

Day 1 focuses on building practical AI-powered applications using Python and Ollama. The goal is to understand how to interact with Large Language Models (LLMs), customize AI behavior using system prompts, maintain conversation history, and create interactive AI applications.

## Technologies Used

- Python
- Ollama
- Llama 3.2
- Git & GitHub

## Projects

### 1. AI Chatbot V3

An interactive chatbot powered by a locally running LLM using Ollama.

**Features:**
- Local LLM integration
- Custom system prompt
- Conversation history
- Interactive chat loop
- Clear conversation functionality
- History command
- Save command
- Exit command
- Message counter
- Error handling

**Run the project:**

```bash
python chatbot_v3.py
```

## Installation

### Prerequisites

- Python 3.10 or later
- Ollama installed
- Llama 3.2 model downloaded

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to Day 1

```bash
cd Agentic-AI-Engineer/Day-01
```

### Step 3: Install Python dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Download the Ollama model

```bash
ollama pull llama3.2
```

### Step 5: Start Ollama

Ensure Ollama is running on your system.

### Step 6: Run any project

```bash
python chatbot_v3.py
```

Or:

```bash
python interview_assistant.py
```

Or:

```bash
python study_assistant.py
```
